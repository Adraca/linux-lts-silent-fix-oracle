# Security Policy

## Reporting Security Issues

We take the security of the Linux kernel and the integrity of this triage tooling seriously.

If you have discovered a vulnerability in this project or have identified a live kernel security issue, unbackported fix with an active exploit vector, or crash reproducer, **please do not open a public issue or discussion**.

### Security Contact

- **Email:** `alert@adraca.io`

### Vulnerability Reporting Guidelines

- **Project Vulnerabilities:** For bugs or security issues within the `fixtriage` codebase itself, email `alert@adraca.io` with reproduction steps and impacted versions.
- **Kernel Exploitation / Live Issues:** Reproducers, PoCs, and actionable exploit details for live kernel vulnerabilities must be reported privately via the security contact above or directly to the Linux kernel security team (`security@kernel.org`) following standard coordinated disclosure practices.
- We will acknowledge receipt of reports within 48 hours and work with upstream maintainers where applicable.
